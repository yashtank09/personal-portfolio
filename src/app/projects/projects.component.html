Sievex


Sievex is a backend-focused automation platform designed to run controlled web-crawling and data-processing workflows.

Users can authenticate, submit validated requests, and execute crawling or automation jobs through secure workflows.

The platform includes secure crawling workflows and AI assistance that uses crawl results and conversation history to answer follow-up questions. Its features include:

  • Authentication and role-based access
  • Spring Security and JWT
  • Dynamic crawling workflows
  • Product-data extraction
  • Job automation
  • Data processing
  • Modular architecture
  • AI-assisted interaction with collected data
  • Conversation-aware contextual assistance

Sievex represents my interest in combining backend engineering, automation, web data, and Generative AI into one platform.

Trade Journal


Trade Journal is a full-stack application designed to help traders understand their trading behavior and performance.

Users can upload broker CSV/Excel files or manually enter trades. The application processes trading executions and transforms them into meaningful trading positions and analytics.

The platform includes functionality such as:

  • CSV and Excel trade ingestion
  • Data cleaning
  • Duplicate detection
  • Trade matching
  • FIFO position calculation
  • Partial position closing
  • Weighted exit-price calculations
  • Realized P&L
  • Trade planning
  • Risk/reward tracking
  • Mistake tracking
  • Trading notes
  • Performance summaries
  • Equity curves
  • Strategy analytics
  • Risk metrics
  • Authentication and authorization
  • Administration and security configuration

The backend follows a modular-monolith architecture using Java 17 and Spring Boot 3, while the frontend is built with Angular.

This project allows me to experiment with real-world software architecture, financial data processing, analytics, security, and application design.
